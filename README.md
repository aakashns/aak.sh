# aak.sh

A monorepo for my open source projects, listed at [aak.sh](https://aak.sh) (from [www](www))

- [collager](collager) - Create framed photo collages in your browser and save or share them as PNGs
- [logspace](logspace) - Self-host your personal website with blog posts, photos, and videos
- [mailmenu](mailmenu) - A macOS menu bar app to track unread email and upcoming calendar events
- [rembox](rembox) - Set up and manage remote development machines
- [screentimer](screentimer) - A macOS menu bar app that shows how long the screen has been on today
- [writui](writui) - A writing app for the terminal. No nonsense. Markdown. Local. Encrypted.
