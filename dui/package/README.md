# @aakashns/dui

Adds [dui](https://dui.aak.sh)'s Datastar components to your project, like shadcn/ui's CLI:
it copies their code into `ui/`, and what they share into `lib/`.

```sh
npx @aakashns/dui add button card   # into src/ if there is one; --dir picks another folder
npx @aakashns/dui list
```

See [Installation](https://dui.aak.sh/docs/installation) for setting up JSX.
