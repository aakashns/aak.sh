Screen Timer

A macOS menu bar app that shows how long your screen has been on today, as a large semi-transparent overlay in a corner of the screen.

View source on GitHub

Features

  • Click-through overlay that fades out when the cursor is over it.
  • Visible on every Space and over full-screen apps.
  • Accurate from launch: reads today's display on/off history from pmset.
  • Choice of corner, size, and transparency from the menu bar.
  • No Dock icon, no Xcode project, no dependencies.

Install

Requires macOS 13+ and a Swift toolchain (xcode-select --install).

git clone https://github.com/aakashns/aak.sh.git
cd aak.sh/screentimer
./install.sh

This builds the app, copies it to /Applications, adds it as a login item, and launches it. Re-run it to update.
